# TDA-EGNN: protein binding-site and cryptic-pocket prediction

Persistent-homology (TDA) features fused into an E(n)-equivariant GNN with ESM2 embeddings, predicting
binding-site residues and cryptic pockets. All training and evaluation runs on Kaggle (T4 GPU / CPU) via the
`kaggle` CLI; notebooks here are what was pushed there.

## Status of the central claim (read before citing any topology result)

Controlled tests found that the gain attributed to topology is largely explained by ordinary burial / shape /
exposure geometry:

* Phase 164: a 2-feature burial baseline already matches the full TDA block on CryptoBench test PR-AUC.
* Phase 228 (official CryptoBench split, 8 seeds): 17 plain geometry features beat TDA alone, and TDA adds nothing
  measurable on top of geometry (geometry+persistence vs geometry, validation PR-AUC p = 0.07 / 0.11).
* Phase 225: the pocket-size correlation reported in the manuscript (partial rho 0.756) is inflated by PR-AUC's
  prevalence-dependent chance level; prevalence-free versions are about 0.30-0.36.
* Phase 226: P2Rank 2.5.1 baseline on the same 185 proteins.
* Phases 232-233: the same control on the manuscript's own evaluation (Phase 166 hard split, 185 proteins, experimental
  ligand-contact labels; the "185-protein holdout" is that split, not the official CryptoBench split). Geometry+persistence vs
  geometry: PR-AUC +0.0008 (95% CI -0.005..+0.007, p = 0.79). Geometry beats P2Rank on ROC (0.796 vs 0.756).
* `cryptic-pocket/phase167_validation/phase234_REVISED_MANUSCRIPT.md` is the revised write-up (the Phase 214 manuscript is
  frozen and predates these controls; see `phase234_CHANGES_FROM_FROZEN.md`).
* Phases 229-230: the same control on the main pipeline (Phase 11 nested CV, 10 folds x 2 seeds, 2,055 chains). Geometry beats
  topology alone (test PR-AUC +0.0129, 10/10 folds); topology adds a small residual over geometry (+0.0097, 9/10 folds, t p = 0.017,
  Wilcoxon p = 0.037; not significant in ROC-AUC).
* Phases 235-237: the same control for localization (COACH420/HOLO4K, pooled DCC@4A, 8 seeds, 35M only). Geometry
  beats topology alone (+0.0305, 7/8 seeds). Geometry+topology vs geometry is null per-seed (+0.0051, 3/8 seeds) but
  a follow-up (Phase 237, reloading the 32 checkpoints) shows a monotonic ensemble-size effect (69/70 disjoint 4-seed
  half-splits positive) and a two-way-bootstrapped +0.0188 (95% CI -0.0096..+0.0456) -- directionally consistent, not
  formally confirmed.
* Phases 238-241: the same classification control re-run at ESM2-650M and ESM2-3B, holding the 2,055-chain pool fixed
  (isolates embedding scale). The residual topology-beyond-geometry effect does NOT shrink with scale -- it becomes
  more robust: 650M +0.0091 PR-AUC (8/10 folds, t p=0.0037, W p=0.0098) and +0.0032 ROC-AUC (9/10, p=0.015/0.037,
  both CONFIRMED); 3B +0.0115 PR-AUC (10/10, p=1.9e-4/0.0020) and +0.0040 ROC-AUC (9/10, p=0.0026/0.014, both
  CONFIRMED) -- versus 35M's PR-AUC-only confirmation. Geometry still matches or beats topology alone at every scale.
  `paper.md` has been updated to match.
* Phases 244-247: the same localization control at ESM2-650M and 3B (benchmark cache re-embedded by lossless one-hot decode,
  no structure re-fetch). Does NOT repeat classification's strengthening: geometry still matches/beats topology alone at every
  scale, and geometry+topology vs geometry is +0.0051 / +0.0206 / -0.0007 per seed at 35M/650M/3B (none confirmed by both tests;
  pooled +0.0084, 95% CI -0.0027..+0.0194, no scale trend). The classification residual is real at 650M/3B; the localization
  residual is not established at any scale. Not yet run: the 7,513-chain pool, CryptoBench at 650M/3B.

* Phases 250-254: the localization control with 3.5x more training data (the 7,513-chain round-3 pool; COACH420, 413 structures
  with a ligand). Adding topology to geometry is NEGATIVE: -0.0242 per seed (geometry better in 7/8 seeds), two-way bootstrap
  -0.0217 (95% CI -0.068..+0.024). Geometry alone is the best arm (8-model ensemble DCC 0.620 vs 0.586 for topology).
  Topology still beats no topology (+0.094, 8/8 seeds).
* Phases 255/257 (classification control at the 7,513-chain pool, 10-fold CV, folds 0-3 on GPU, 4-9 on CPU): complete.
  Geometry+topology minus geometry = +0.0035 PR-AUC (CI -0.0008..+0.0078, not confirmed) and +0.0018 ROC-AUC (confirmed, tiny).
  Geometry alone beats no-topology by +0.062 PR-AUC in 10/10 folds. Same-fold CPU-vs-GPU check (folds 0/1): CPU is 0.002 lower PR-AUC / 0.001 lower ROC-AUC, about the size of the topology residual itself.
* Phase 262 (CryptoBench, ESM2-3B, official split, from scratch, 8 seeds x 4 arms): geometry +0.021 test PR-AUC over no-topology
  (7/8 seeds, t p=0.041, Wilcoxon p=0.078); topology adds nothing on top. Still below the 3B transfer model (ROC 0.911).
* Phases 260/261 (local, no new training): P2Rank blend (+0.014 protein PR-AUC) and multi-candidate localization (best of 3
  clustered guesses: 74% within 10 A, 60.8% within 8 A; single guess 20.4% within 4 A vs P2Rank top-1 13.8%).

* Phases 263/264/265 (geometry-aware 3B transfer; ESM2-3B, official CryptoBench split, 8 seeds/arm): geometry adds nothing to transfer
  (geom+topo - topology-only: -0.003 PR-AUC, p=0.53; ensemble ROC 0.912-0.914 for all arms). Transfer itself beats from-scratch by +0.058 PR-AUC.
  MMseqs2 leak check: 135/182 test chains have a >=30%-identity homolog in the pretraining pool; the transfer gain survives on the 47 that do not.

* Phase 266 (homology-clean transfer): removed the 174 pool chains homologous (>=30% id) to any CryptoBench val/test chain, retrained 3B
  checkpoints on 7,004 chains, refit CryptoBench. All 182 test chains now homology-clean: per-seed PR 0.408 / ROC 0.896 / DCC4 0.298
  (ensemble ROC 0.911), same as leaky-pool transfer (p=0.86) and +0.059 PR-AUC over from-scratch (8/8 seeds). The transfer gain is not a leak.

* Phases 267/268 (multi-candidate localization + P2Rank blend on the official split, clean-pool transfer ensemble, 179 test chains): single
  guess hits within 4 A for 35.8% vs P2Rank top-1 16.1%; hybrid best-of-3 hits 37.4% (4 A) / 71.5% (8 A) vs P2Rank best-of-3 25.3% / 57.5%
  (paired p=0.007 / 0.001). Blend with P2Rank adds nothing to the transfer model (stack weight ~0; PR-AUC -0.004).

* Phase 269 (small-pocket loss weighting, 2 strengths x 8 seeds, clean-pool 3B transfer): NEGATIVE. Small-pocket (<=8 residue) test ROC-AUC
  +0.002 / +0.006 (p=0.55 / 0.14); the stronger weight slightly hurt pooled PR-AUC (-0.008, p=0.002) and DCC@4 (-0.024). The small-pocket gap
  (ROC 0.69 vs 0.90-0.93; DCC@4 8% vs 36-50%) is a signal limit, not a loss-balance problem.

* Phases 270-272 (protein-movement / elastic-network features, matched control, homology-clean 3B pretraining + transfer, 8 seeds): NULL.
  Pooled test PR-AUC +0.0042 (p=0.60), ROC-AUC +0.0059 (p=0.089); no improvement on the small-pocket stratum the idea targeted (ROC -0.006). Not adopted.

* Phases 273-275 (per-residue chemistry features -- hydropathy/charge/aromaticity/H-bond/hydrophobic-patch, matched control, same design as
  Phases 270-272, 8 seeds): INCONCLUSIVE. Pooled PR-AUC +0.0112 (t p=0.046, Wilcoxon p=0.055 -- split verdict, not confirmed); ROC-AUC +0.0011 (p=0.75);
  small-pocket DCC@4 went down (-0.026, also split-verdict). Not adopted.

* Phase 276 (external audit, no new training): an independent relabeling of the CryptoBench test split ("A benchmark
  selected for crypticity", github.com/pmfran4252-afk/cryptic-site-benchmark) finds only 17/182 test proteins are truly
  cryptic by a strict apo/holo rule; on those, our headline model's pooled ROC falls 0.896->0.721 but it beats our own
  P2Rank rerun by +0.115 precision@20 (n=16, paired, p=0.022/0.022, CI excludes 0) -- above every baseline in their table.
  Their claim that geometry/cavity features hurt cryptic sites does not replicate on our architecture (trends positive, NS).

* Phase 277 (external validation, genuinely new structures, not just a relabeling): PocketMiner's 35-protein MD-derived test set and 99
  cryptic entries from an independent adversarial benchmark, fetched and featurized fresh, scored with the unmodified headline model.
  PocketMiner: pooled ROC 0.925 (all) / 0.920 (6 proteins with no training-pool homolog) -- beats PocketMiner's own reported 0.87 on their
  own dataset. cryptic-site-benchmark: pooled ROC 0.833 (all) / 0.757 (16 homology-clean) -- consistent with Phase 276's internal 0.721 on
  CryptoBench's own truly-cryptic subset. Two independent groups, two cryptic definitions, the same ~0.72-0.76 ROC-AUC on truly hard sites.
* Phase 280 (extend CryptoBench training with 1,997 homology-clean chains from a second benchmark, same recipe, 8 seeds): NEGATIVE and
  confirmed. Test PR-AUC -0.0272 (0/8 seeds, p=0.005/0.008), MCC -0.0253 (p=0.018/0.016). Real, correctly-labelled extra training data,
  naively pooled with no recipe re-tuning, measurably hurt this model. Not adopted.
* Phase 278/281 (real GPU-accelerated MD pilot, 17 truly-cryptic CryptoBench test proteins, 5ns each after fixing a real infra problem --
  pip's OpenMM has no CUDA platform; the box's "mamba" is an unrelated tool; a from-scratch conda-forge bootstrap got CUDA working, 15ns/hr,
  88x speedup): WEAK/NULL, underpowered. Session was cancelled by the platform after ~14h with only 8/17 proteins done. Pooled AUC of real
  MD features vs the true site label: RMSF 0.500 (exactly chance), neighbour-count-delta features 0.37-0.64 (mixed, modest). Not pursued
  further at this scale; a properly long/enhanced-sampling MD run remains untested and would need real dedicated infrastructure.
* Phase 282 (calibration check, headline model, no new training): POSITIVE, real, cheap. Raw probabilities badly overconfident (at the
  model's own top decile, 0.838 predicted vs 0.331 actual positive rate; ECE 0.166). Isotonic regression fit on the existing 60-chain
  validation set fixes nearly all of it (ECE 0.166 -> 0.0029, Brier 0.090 -> 0.033) without changing any ranking/AUC result. Holds up
  reasonably on the hardest subgroups too (cryptic ECE 0.154->0.021; small-pocket ECE 0.203->0.025, still the worst-calibrated group).
  Follow-up (still Phase 282): fitting a SEPARATE isotonic curve per pocket-size stratum (small <=8 residues vs larger, both fit on the
  validation split only) closes most of that residual gap -- small-pocket ECE 0.025 -> 0.0039, larger 0.0106 -> 0.0048 -- at no cost to
  the pooled test number (ECE 0.0029 vs 0.0030, a wash; Brier/log-loss both improve slightly). Bonus: also improves the cryptic/pre-formed
  breakdown it never saw during fitting. Adopted as the recommended calibration (size-stratified, not pooled) for any deployment.
