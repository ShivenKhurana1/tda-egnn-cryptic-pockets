# TDA-EGNN: protein binding-site and cryptic-pocket prediction

Persistent-homology (TDA) features fused into an E(n)-equivariant GNN with ESM2 embeddings, predicting
binding-site residues and cryptic pockets. All training and evaluation runs on Kaggle (T4 GPU / CPU) via the
`kaggle` CLI; notebooks here are what was pushed there.

## Layout

## Status of the central claim (read before citing any topology result)

Controlled tests found that the gain attributed to topology is largely explained by ordinary burial / shape /
exposure geometry:

* Phase 164: a 2-feature burial baseline already matches the full TDA block on CryptoBench test PR-AUC.
* Phase 228 (official CryptoBench split, 8 seeds): 17 plain geometry features beat TDA alone, and TDA adds nothing
  measurable on top of geometry (geometry+persistence vs geometry, validation PR-AUC p = 0.07 / 0.11).
* Phase 225: the pocket-size correlation reported in the manuscript (partial rho 0.756) is inflated by PR-AUC's
  prevalence-dependent chance level; prevalence-free versions are about 0.30-0.36.
* Phase 226: P2Rank 2.5.1 baseline on the same 185 proteins.
* Phases 232-233: the same control on the manuscript's own evaluation (Phase 166 hard split, 185 proteins, experimental
  ligand-contact labels; the "185-protein holdout" is that split, not the official CryptoBench split). Geometry+persistence vs
  geometry: PR-AUC +0.0008 (95% CI -0.005..+0.007, p = 0.79). Geometry beats P2Rank on ROC (0.796 vs 0.756).
* `cryptic-pocket/phase167_validation/phase234_REVISED_MANUSCRIPT.md` is the revised write-up (the Phase 214 manuscript is
  frozen and predates these controls; see `phase234_CHANGES_FROM_FROZEN.md`).
* Phases 229-230: the same control on the main pipeline (Phase 11 nested CV, 10 folds x 2 seeds, 2,055 chains). Geometry beats
  topology alone (test PR-AUC +0.0129, 10/10 folds); topology adds a small residual over geometry (+0.0097, 9/10 folds, t p = 0.017,
  Wilcoxon p = 0.037; not significant in ROC-AUC).
* Phases 235-237: the same control for localization (COACH420/HOLO4K, pooled DCC@4A, 8 seeds, 35M only). Geometry
  beats topology alone (+0.0305, 7/8 seeds). Geometry+topology vs geometry is null per-seed (+0.0051, 3/8 seeds) but
  a follow-up (Phase 237, reloading the 32 checkpoints) shows a monotonic ensemble-size effect (69/70 disjoint 4-seed
  half-splits positive) and a two-way-bootstrapped +0.0188 (95% CI -0.0096..+0.0456) -- directionally consistent, not
  formally confirmed.
* Phases 238-241: the same classification control re-run at ESM2-650M and ESM2-3B, holding the 2,055-chain pool fixed
  (isolates embedding scale). The residual topology-beyond-geometry effect does NOT shrink with scale -- it becomes
  more robust: 650M +0.0091 PR-AUC (8/10 folds, t p=0.0037, W p=0.0098) and +0.0032 ROC-AUC (9/10, p=0.015/0.037,
  both CONFIRMED); 3B +0.0115 PR-AUC (10/10, p=1.9e-4/0.0020) and +0.0040 ROC-AUC (9/10, p=0.0026/0.014, both
  CONFIRMED) -- versus 35M's PR-AUC-only confirmation. Geometry still matches or beats topology alone at every scale.
  `paper.md` has been updated to match.
* Phases 244-247: the same localization control at ESM2-650M and 3B (benchmark cache re-embedded by lossless one-hot decode,
  no structure re-fetch). Does NOT repeat classification's strengthening: geometry still matches/beats topology alone at every
  scale, and geometry+topology vs geometry is +0.0051 / +0.0206 / -0.0007 per seed at 35M/650M/3B (none confirmed by both tests;
  pooled +0.0084, 95% CI -0.0027..+0.0194, no scale trend). The classification residual is real at 650M/3B; the localization
  residual is not established at any scale. Not yet run: the 7,513-chain pool, CryptoBench at 650M/3B.

* Phases 250-254: the localization control with 3.5x more training data (the 7,513-chain round-3 pool; COACH420, 413 structures
  with a ligand). Adding topology to geometry is NEGATIVE: -0.0242 per seed (geometry better in 7/8 seeds), two-way bootstrap
  -0.0217 (95% CI -0.068..+0.024). Geometry alone is the best arm (8-model ensemble DCC 0.620 vs 0.586 for topology).
  Topology still beats no topology (+0.094, 8/8 seeds).
* Phase 255 (classification control at the 7,513-chain pool): INCOMPLETE. Only folds 0-3 of 10 finished before Kaggle's
  30-hour weekly GPU quota ran out; folds 4-9 (kernels 255c/d/e) are queued behind a retry script. The finished folds point the
  same way as the smaller pool (geometry+topology better than geometry in 4/4 folds, +0.007 PR-AUC) but four folds cannot
  meet the project's two-test rule, so they are not reported in `paper.md` as a result.
